# AI Usage

## Overview

AI tools were used as a learning and development assistant while building SecureNotes.

## How AI Was Used

- Provided guidance for implementing Argon2 password hashing, sessions, input validation, and rate limiting.
- Suggested UI structure and did the CSS styling.
- Assisted with project documentation such as `README.md` and `DECISIONS.md`.

## Developer Contribution

The project was developed, modified, and tested locally by the developer.

The developer was responsible for:

- Developing the backend using python and flask.
- Creating and managing the database
- Writing html code for frontend (without css)
- Integrating security features
- Testing the application
- Debugging and making final decisions

AI-generated suggestions were reviewed and tested before being included.

## AI Limitations

AI was used as a learning and development aid, not as a replacement for understanding, implementation, or testing.

The final implementation was verified locally by the developer.
